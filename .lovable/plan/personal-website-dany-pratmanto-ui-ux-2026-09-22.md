# Personal Website Dany Pratmanto — UI/UX

## Ringkasan

Membangun antarmuka website personal Dany Pratmanto sebagai dosen dan software developer. Implementasi hanya sisi tampilan dan interaksi; seluruh isi diletakkan dalam berkas JSON mock terpisah tanpa database, login, atau layanan server.

## Yang akan dibangun

- Halaman utama lengkap: navigasi, perkenalan, dua jalur pengunjung, proyek unggulan, layanan, materi terbaru, artikel, profil, ajakan konsultasi, dan footer.
- Halaman Portfolio, Services, Materi Kuliah, Articles, About, dan Contact yang dapat dibuka dari navigasi.
- Detail visual untuk proyek, mata kuliah, dan artikel menggunakan data mock yang sama.
- Pencarian dan filter materi di sisi tampilan, navigasi mobile, serta tombol dan tautan yang memiliki respons interaksi.
- Foto profil Dany dari berkas yang diberikan sebagai aset utama.

## Arah visual

- Minimalis teknis dan personal, bukan korporat: dasar off-white, teks gelap, abu netral, dan satu aksen biru.
- Space Grotesk untuk judul dan DM Sans untuk isi.
- Susunan asimetris dengan tipografi kuat, garis/grid halus, ruang lapang, sudut kecil, dan gerak yang lembut.
- Proyek ditampilkan sebagai visual antarmuka bergaya editorial tanpa membuat klaim teknis baru.
- Mobile memprioritaskan pencarian materi, akses mata kuliah, dan konsultasi.

## Data dan struktur

- Membuat berkas JSON mock terpisah untuk profil, navigasi, proyek, layanan, harga, mata kuliah/materi, artikel, dan testimonial.
- Komponen tampilan membaca JSON tersebut sehingga isi mudah diganti tanpa mengubah struktur halaman.
- Tidak ada penyimpanan permanen, dashboard admin, login, database, atau pengiriman formulir nyata.

## Pemeriksaan

- Memastikan semua halaman dapat dinavigasi dan tidak ada tautan internal yang buntu.
- Memeriksa tampilan desktop dan ponsel, keterbacaan, tidak ada elemen bertumpuk, serta pencarian/filter materi bekerja.
- Menambahkan judul dan deskripsi unik untuk setiap halaman.
